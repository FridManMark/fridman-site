Что такое FridMan?

FridMan — это Android-приложение для инъекции JavaScript-скриптов в процессы с помощью Frida. Работает полностью автономно на устройстве через встроенный frida-inject без необходимости в frida-server, ADB или компьютере.

Как работает FridMan

Принцип работы

Общая схема

FridMan работает как foreground-сервис с плавающим overlay-окном. Внутри окна запущен WebView с полноценным интерфейсом. Все root-команды выполняются через su, а скрипты инжектируются через встроенный frida-inject.

Процесс инъекции
1. Пользователь выбирает процесс из списка → запоминается как текущая цель
2. Нажимает Run → приложение находит PID целевого процесса через системную команду
3. Приложение автоматически готовит скрипт и запускает встроенный frida-inject
4. stdout/stderr процесса читается в реальном времени → логи появляются в терминале
Передача команд в скрипт
1. Пользователь пишет команду в терминале или нажимает плавающую кнопку
2. Приложение записывает команду в файл /data/local/tmp/frida_commands.txt с правами 777
3. Скрипт (через setInterval каждые 500ms) читает файл через нативные вызовы libc
4. Выполняет команду через eval() и очищает файл
5. Результат выводится через console.log() → перехватывается Frida → попадает в терминал
Ключевая особенность

Скрипт сам стирает файл команд после прочтения — дубликатов команд не бывает. Это надёжнее, чем очереди или сокеты.

Хранение данных
Где что лежит
  • Скрипты пользователя — хранятся внутри приложения, доступны через раздел "My Scripts"
  • Временный скрипт — копируется в cache при каждой инъекции
  • Настройки — размер иконки, прозрачность, масштаб, позиции кнопок
  • frida-inject — уже встроен в приложение и используется автоматически
  • frida_commands.txt — файл-мост команд, создаётся автоматически
Связь интерфейса и системы

Интерфейс внутри плавающего окна общается с системой через специальный мост:

Действие в UI Что происходит
Обновить список процессов Выполняется системная команда сканирования
Запустить скрипт Автоматическая подготовка и запуск встроенного frida-inject
Отправить команду Запись в файл-мост команд
Сохранить скрипт Запись в хранилище приложения
Переместить окно Обновление позиции overlay

Важно

Все вызовы между интерфейсом и системой асинхронные — UI не блокируется во время выполнения root-команд.

Шаблон скрипта с мостом команд

Используйте этот шаблон для начала работы. Он включает мост команд для работы с терминалом:

// === МОСТ КОМАНД (обязательно!) ===
const CMD_PATH = "/data/local/tmp/frida_commands.txt";
const libc = Process.getModuleByName("libc.so");

const openF = new NativeFunction(libc.getExportByName("open"), "int", ["pointer", "int", "int"]);
const readF = new NativeFunction(libc.getExportByName("read"), "int", ["int", "pointer", "int"]);
const closeF = new NativeFunction(libc.getExportByName("close"), "int", ["int"]);

const O_RDONLY = 0, O_WRONLY = 1, O_TRUNC = 512;

function readCmd() {
  const p = Memory.allocUtf8String(CMD_PATH);
  const fd = openF(p, O_RDONLY, 0);
  if (fd < 0) return null;
  const buf = Memory.alloc(4096);
  const n = readF(fd, buf, 4095);
  closeF(fd);
  if (n <= 0) return "";
  return buf.readUtf8String(n);
}

function clearCmd() {
  const p = Memory.allocUtf8String(CMD_PATH);
  const fd = openF(p, O_WRONLY | O_TRUNC, 0);
  if (fd >= 0) closeF(fd);
}

function execCmd(raw) {
  let cmd = raw.trim();
  if (!cmd) return;
  console.log("[CMD] >> " + cmd);
  try {
    if (!cmd.includes("(") && typeof globalThis[cmd] === "function") cmd += "()";
    (1, eval)(cmd);
    console.log("[CMD] OK: " + cmd);
  } catch (e) {
    console.log("[CMD] ERR: " + e.message);
  }
}

setInterval(() => {
  const c = readCmd();
  if (c !== null && c.trim().length > 0) {
    clearCmd();
    execCmd(c);
  }
}, 500);

// === ВАШИ КОМАНДЫ ===
globalThis.help = function() {
  console.log("help() - show commands");
};

console.log("[+] Script ready. Type help()");
Работа с командами

Все команды передаются через файл /data/local/tmp/frida_commands.txt

Команда Описание
help() Показать список команд
help То же самое (скобки добавятся автоматически)
dump() Запустить дамп памяти
search("text") Поиск строки в памяти
Важные правила
  • Все команды должны быть функциями в globalThis
  • Всегда используйте try/catch в командах
  • Логи пишите только на английском (русский ломается)
  • Не используйте fs.* — в Frida нет Node.js API
  • Используйте setInterval чтобы скрипт не завершался
Плавающие кнопки

Создавайте кнопки для быстрого вызова команд:

  • Название кнопки: Текст на кнопке (например "Help")
  • Команда: Что выполнить (например "help()")
  • На экране: Кнопка появляется поверх всех приложений

Tap = отправить команду, Drag = переместить, Long-press = удалить

Работа с терминалом

Терминал показывает логи скрипта и позволяет отправлять команды:

  • Send command... — поле для ввода команд
  • Copy all — скопировать весь вывод
  • Clear — очистить терминал
  • Long-press + drag — выделение текста для копирования
Готово к работе
